# Visual assets

Original vector artwork created for this project: `logo.svg`, `banner.svg` and `recovery.svg`. The mark combines a durable queue, a returning retry path and a committed check. Flat navy, amber and mint colors distinguish queue, retry and success; text and numeric steps also communicate meaning. SVG backgrounds and foregrounds are explicit so GitHub light and dark themes retain contrast. No fonts, scripts, trackers, external images or stock photos are embedded.

`../dashboard.png` and `../dashboard-mobile.png` are real captures from the running synthetic app, generated by the existing Playwright Chromium runtime through `qa_demo.py`. They are runtime evidence, unlike the clearly labeled recovery illustration. README image descriptions and surrounding prose explain what each image demonstrates. Click the mobile capture for full resolution; its table scrolls inside the app.

Tools used: Ponytail skill for scope, hand-authored SVG for the original graphics, existing Python/Playwright for isolated browser rendering and QA, and Git/GitHub CLI for publication. Figma, Canva and ImageGen capabilities were inspected in the available tool inventory; they were not invoked because editable vector artwork and real app captures fit this update. Taste and Vercel skills were not found in the available skill catalog or local skill locations checked; no new plugins or account permissions were added.
